# Support

## Usage questions

Open a [GitHub issue](https://github.com/euvoor/dwm-status/issues/new) for a
focused question about installing, configuring, or running `dwm_status`. Search
the README and existing issues first.

Include the relevant facts:

- Linux distribution and kernel;
- Rust version and the commit or installed binary being run;
- how the X session and `dwm` are started;
- relevant configuration with secrets and identifying data removed;
- exact command, stderr, and the smallest useful log excerpt;
- `xprop` output when the root-window value is involved.

The project does not provide general support for Linux, `dwm`, X11, Rust,
NVIDIA drivers, fonts, or shell startup files.

## Bugs and feature proposals

Use a separate issue for each reproducible bug or concrete proposal. For bugs,
include reproduction steps, expected behavior, actual behavior, and whether the
problem reproduces with the checked-in sample config. For proposals, explain
the machine and workflow that need the change.

## Security and conduct

Report suspected vulnerabilities through the private route in
[`SECURITY.md`](SECURITY.md). Follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)
for conduct reports. Do not put private, identifying, or security-sensitive
details in a public issue.
